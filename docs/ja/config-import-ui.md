# 管理画面での設定インポートとエクスポート

**システム → エクスポート / インポート**を開きます。エクスポートは、元ノードとアプリのバージョン、内容の範囲を含むバージョン 2 の JSON です。設定と有効な `secret:` 参照を含みますが、安全な保存領域の値や素材ファイルは含みません。古い平文パスワード、トークン、秘密鍵、認証情報を含む URL は除外し、`excluded_paths` に一覧を記録します。無関係な文章は保持し、資格情報を伏せ字の代替値に置き換えません。完全な復旧用バックアップではありません。

JSON ファイルを選ぶか貼り付け、**インポートを確認**を選択します。バージョン 2 のエクスポート、設定オブジェクト、旧形式の項目配列を[段階的インポート](config-import.md)に変換します。未対応のバージョン、重複 JSON キー、予約された prototype キー、サイズ超過は事前に拒否します。通常の書き込みの 256 操作上限は変えず、Core のインポートと履歴の上限内で 256 項目を超える復元に対応します。

既定では最新スナップショットへ入力項目を結合し、省略された項目は残します。明示的な全体置換では省略項目を削除します。変更・削除、秘密情報と素材の不足、エクスポートからの除外項目を確認してください。事前確認は稼働中の設定を変更しません。不足や不正な設定があれば適用できません。既存の連携設定または安全な保存機能で秘密情報を再登録し、素材ページでファイルをアップロードしてから、古いプレビューを破棄して再確認します。設定 JSON に秘密情報の値を貼り付けないでください。設定が途中で変わった場合も自動上書きせず、明示的な再確認が必要です。

削除件数と対象ノードを示すチェックボックスに同意し、**確認済みの設定を適用**を押した場合のみ、ランダムな操作 ID を作成してコミットします。送信前に、このタブの sessionStorage へ秘密情報を含まない復旧情報（schema version、operation ID、stage token、digest、node ID）だけを保存します。ファイル内容、資格情報、プレビューは保存しません。タブを閉じる場合は表示された復旧情報を控えてください。認証期限切れでファイル入力を消去し、復旧情報は保持します。事前確認を開始したセッションが無効なら再確認が必要です。

応答の消失、不正、切断では結果は不明です。**このインポートの結果を確認**は元ノードの同じ操作を照会するだけで、ステージを実行しません。再読み込みも照会用の情報のみ復元します。新しい操作は自動送信しません。記録が見つからなくても結果は不明のままです。別のインポートを準備する場合は、古い復旧情報を保存し結果が不明のままであることに明示的に同意してください。次の確認中も古い情報を表示し、次のコミットでタブ内の保存情報を置き換えます。再起動後の再ログインでも、元の管理者資格情報が有効な間は記録を照会できます。

成功表示は、このノードでの永続コミットのみを意味します。ノードごとの特定リビジョンの確認 API はないため、他ノードへの設定同期は**未確認**と表示します。別表示のオンライン台数と既知ノード数は観測した接続状態のみで、同期の進捗や全体成功を意味しません。
