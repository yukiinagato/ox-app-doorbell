# 管理页面配置导入与导出

打开**系统 → 导出 / 导入**。导出为版本 2 JSON，包含来源节点、应用版本和内容范围。文件包含配置及有效 `secret:` 引用，不含安全存储秘密值或资源文件。遗留明文密码、令牌、私钥和携带凭据的 URL 会被排除，`excluded_paths` 列出遗漏字段；无关文本保持不变，不以脱敏占位符替代可用凭据。这不是完整的灾难恢复备份。

选择 JSON 文件或粘贴内容，再按**预览导入**。版本 2 导出、原始配置对象及旧条目数组会转换为[分阶段导入协议](config-import.md)。不支持的版本、重复 JSON 键、保留的 prototype 键及超大输入会在暂存前拒绝。普通写入仍保持 256 操作限制；本流程可在 Core 的导入及历史容量范围内恢复超过 256 项。

默认把输入字段合并到最新快照，缺省字段保留；明确选择完整替换后，缺省字段会删除。请检查全部更改、删除、缺失的秘密引用和资源，以及导出遗漏字段。预检不会修改运行配置；缺少依赖或配置无效时不能确认提交。请通过现有集成或平台安全存储功能重新配置秘密值，通过资源页上传文件，然后丢弃旧预览并重新预检。不要把秘密值粘贴进配置 JSON。期间配置发生变化时必须明确重新预检，不会自动覆盖。

勾选显示删除数量和本地目标的确认框，再按**应用已确认的导入**，才会生成随机操作标识并提交。发送前会在本标签页 sessionStorage 保存非敏感恢复记录：schema version、operation ID、stage token、digest、node ID；不保存文件内容、凭据或预览。关闭标签页前请自行保留显示的恢复记录。登录失效会清除文件输入并保留记录；预检发起会话失效时必须重新预检。

提交响应丢失、无效或中断时，结果显示为未知。**查询此次导入结果**只在原节点读取同一操作的记录，不会执行暂存配置；刷新页面也只恢复查询上下文。不会自动提交新操作。未找到回执仍是结果未知。要准备另一导入，必须明确勾选已保存旧恢复记录并理解旧结果仍未知；下一轮预览仍显示旧记录，下一次提交会替换标签页保存的记录。重启后重新登录，只要原管理员凭据仍有效，即可查询已有回执。

成功仅表示此节点完成持久提交。当前没有公开 API 可证明每个节点已确认某一配置版本，因此其他节点的配置同步明确显示为**尚未验证**。另列的在线数和已知节点数仅表示观察到的连接状态，不代表同步进度或全网成功。
